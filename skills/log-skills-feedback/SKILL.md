# Log Skills Feedback — Compatibility Entry
Use the [Kaizen workflow](../kaizen/SKILL.md) for incident capture, evidence review, and proposals. This name remains for older callers; it is not a second process.

Never append to `agents/skills-feedback-log.md` or any public repository as a fallback. Resolve the declared private project store or configured private global store through Kaizen. Capture and analysis do not authorize changes to standing guidance; obtain the user's explicit approval for a proposed change unless the existing request already covers it.

If the Kaizen skill or private store is unavailable, report that limitation in the current authorized conversation. Do not invent a destination or convert a general idea into an incident merely to fit this legacy trigger.
